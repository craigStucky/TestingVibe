# Steady Strength

A small exercise tracker and beginner program for home training with gymnastics rings, one weight, a mat and a jump rope. Built for someone starting out after a lot of desk time, with extra care for shoulder and neck tension.

## Using it

Open `index.html` in a browser (works on a phone). No install, no account. Data is saved in that browser only, so use **Progress → Export backup** now and then.

To use it on your phone from anywhere, turn on GitHub Pages for this repo (Settings → Pages → deploy from branch) and open the link it gives you.

## The program

- **3 workouts a week**, alternating A and B, with a rest day between (e.g. Mon / Wed / Fri). About 30 minutes each.
- **Weeks 1–2: 2 sets** per exercise. **Week 3 onward: 3 sets.**
- **Flow day (optional, any day)**: sun salutations. One set = 24 poses (12 leading with the right leg, 12 with the left). Guided mode walks you through each pose with breath cues and counts sets. Starts at 2 sets with shoulder-friendly versions (knees down, knees-chest-chin, low cobra); chaturanga and upward dog come at the top level.
- **Desk breaks every day**: a 4-minute routine a few times a day (chin tucks, shoulder blade squeezes, neck and chest stretches).
- Each session: 5-minute warm-up → exercises → jump rope finisher → 3-minute cool-down.

| Workout A | Workout B |
|---|---|
| Ring row | One-arm row (weight) |
| Squat (goblet with weight) | Hip hinge / Romanian deadlift (weight) |
| Push-up (starts at the wall) | Ring face pull |
| Glute bridge | Split squat |
| Dead bug | Prone Y-T raise |
| Jump rope finisher | Side plank |
| | Jump rope finisher |

### Progression

Every exercise has levels, from very easy to harder. Start at level 1. When you hit the top of the rep range on every set, it didn't feel hard, and shoulder discomfort was 2/10 or less, the app suggests leveling up. With only one weight, progress comes from harder variations and slower lowering.

### Shoulder-friendly choices

- More pulling than pushing, to balance desk posture.
- No ring dips, ring push-ups, ring support holds or overhead pressing for the first 2–3 months.
- Shoulders stay down, away from the ears. Muscle burn is fine; sharp or pinching pain means stop and drop a level.

This is general fitness guidance, not medical advice. If shoulder cramps are frequent, severe, or come with numbness or tingling, get them checked by a doctor or physiotherapist.
